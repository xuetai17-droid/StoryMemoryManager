# Story Memory Manager v0.5.5 source 主序版

核心修正：
- 同一天内，原始聊天 source 编号是剧情先后顺序的最高优先级。
- 时间文本（如 22:00、22:30）只用于显示和辅助判断，不再决定同日事件排序。
- 如果出现 #67 → #80 → #100，但摘要时间写成 22:30 → 22:00 → 22:00-23:59，界面仍按 #67 → #80 → #100 显示。
- 时间文本与 source 顺序冲突时，加入“时间线校准检查”，不会擅自重排剧情。
- 保留 v0.5.4 的前夜→次日凌晨归属修正。
- 保留断点安全重建、重建中可视化、重复事件合并与高置信跨日修正。
- 不修改原始聊天，只修改插件记忆结构。
