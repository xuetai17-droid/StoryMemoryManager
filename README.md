# 剧情自动记忆 Story Memory Manager

版本：0.2.3

SillyTavern 长线 RP 自动记忆扩展。安装一次，可用于不同角色卡和不同聊天；记忆按“聊天”隔离。

## 功能

- 每个聊天独立记忆，避免角色卡之间串台。
- 自动增量总结；默认每 8 条新消息触发一次。
- 可重新扫描整条旧聊天。
- 可导入/导出 JSON。
- 独立维护“剧情时间”，不把 SillyTavern 楼层发送时间当成剧情时间。
- 时间优先级：用户正文明确时间 > 相对时间推进 > 连续事件 > AI `<date>`。
- 保存时间线、事实、事件、人物、关系、未完成事项、冲突和隔离记忆。
- 使用当前 SillyTavern 已连接的模型做后台总结，不在本插件保存 API Key。
- 在正常生成前临时注入当前聊天记忆。

## 当前这条旧剧情的第一次使用

1. 安装并启用本扩展。
2. 打开目标聊天。
3. 点击右下角“记忆”。
4. 点“导入记忆 JSON”。
5. 选择已经清洗好的 `剧情主记忆_清洗重建版_v2.json`。
6. 确认面板显示当前剧情时间为 `2025-09-21 02:25`。
7. 保持“生成时自动注入记忆”和“自动增量总结”开启。
8. 继续正常聊天即可。

## 新角色卡 / 新聊天

不需要导入旧 JSON。打开新聊天后直接开始聊天，插件会在达到触发条数后建立自己的记忆。也可以手动点“总结新增”。

## 注意

- LLM 总结不能保证绝对无误，因此插件保留 `conflicts` 和 `quarantined`。
- “重扫整条聊天”不会删除原始聊天，只重建本插件存在 chatMetadata 里的记忆。
- 如果当前模型/后端不支持 Structured Outputs，插件会自动尝试普通 JSON 输出作为回退。
- 第三方扩展有执行前端 JavaScript 的权限，只应安装你信任的扩展。

## 文件

- `manifest.json`：SillyTavern 扩展声明。
- `index.js`：核心逻辑。
- `style.css`：移动端友好界面。


## v0.2.1 修复

- 修复部分 SillyTavern 构建中安装成功但界面按钮未出现的问题。
- 除 `activate` lifecycle hook 外，脚本载入后也会主动初始化 UI；即使 `APP_READY` 已经触发也可以显示“记忆”按钮。

## v0.2.2 兼容性修复

- 不再依赖 `hooks.activate` 生命周期才能启动。
- 脚本加载后直接初始化，并在 DOMContentLoaded / APP_READY / APP_INITIALIZED 多阶段兜底。
- 专门处理“扩展显示已安装且启用，但手机端看不到记忆按钮”的情况。

## v0.2.3 诊断

页面加载后会无条件显示橙色 `SMM诊断` 按钮。
它不依赖 SillyTavern context，用于判断入口 JS 是否被真正执行。
