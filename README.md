# Story Memory Manager v0.6.1 时间来源校验版

本版处理“晚间/凌晨/约22:00 到底从哪里来的”问题。

时间可信等级：
- explicit：明确时间。事件文本本身可验证到 HH:MM / 时间区间 / 明确日期+钟点。
- fuzzy：模糊时间。事件文本只有“凌晨/上午/下午/晚间”等原始时段词。
- inferred：推测时间。时间只存在于旧总结的 time 字段，在事件文本中找不到依据。
- uncertain：无法验证。
- none：没有时间。

规则：
- 只有 explicit / 有来源的 fuzzy 才允许参与跨午夜判断。
- inferred 不参与日期推进。
- 生成新记忆时禁止模型自行补“晚间/凌晨/约22:00”。
- 原文没有时间就留空，不猜。
- 不修改原始聊天。
