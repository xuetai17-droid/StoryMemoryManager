# Story Memory Manager v0.11.20 HYBRID

本版重点修复主聊天模型（例如冥王星）拿不到当前聊天 SMM 连续性记忆的问题。

- 每次聊天切换、消息收发/编辑/删除后的 refresh 都重新同步安全 extension prompt。
- 新增“检查本轮会注入给主模型的记忆”，可直接看到注入是否关闭、是否被断档保护阻止，以及实际注入文本。
- 不改变角色卡/世界书优先级；SMM 只提供连续性事实。
- 保留 v0.11.18 JSON 容错与自然时间粒度修复。

本版在 v0.11.17 HYBRID 上收口两个问题：

1. **API JSON 容错**：轻微格式错误优先本地修复，避免因为一个逗号、裸属性名或调试字段重新消耗一次完整总结 API。
2. **历史时间显示恢复自然粒度**：变量状态提供的分钟级时间继续用于底层排序，但 UI 默认显示“上午/下午/晚间”等自然时段；原文或结构化摘要明确给出的具体时分仍保留。

建议升级后先正常使用，不需要为了本版重新跑全部历史总结。若之前某一批因为 JSON 解析失败而没有提交，可只重新执行那一批。
