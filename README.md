# Story Memory Manager v0.5.9 source 跨午夜状态机版

核心修复：
- 以 source 原始消息顺序为唯一剧情骨架。
- 检测“晚间/深夜 → 凌晨/半夜”时，日期 +1。
- 跨日后，后续上午/下午/晚间仍保持该新日期，不会再次 +1。
- “凌晨 → 晚间”不是跨日。
- 明确“次日/第二天/翌日/隔天”仍可触发 +1。
- 明确绝对日期优先。
- 不修改原始聊天，只重建插件记忆日期。

当前案例期望：
#67,#69 晚间22:30 = 9月11日
#71-#79 凌晨 = 9月12日
#80... 晚间22:00 = 仍然9月12日
#100... 晚间22:00-23:59 = 仍然9月12日
